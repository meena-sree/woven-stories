# Lessons Learned

This project helped me gain practical experience with the complete lifecycle of a WordPress website.

## Technical Learning

- WordPress installation and configuration
- WooCommerce store setup
- SEO implementation
- Performance optimization
- Website security
- Backup and recovery
- FTP and File Manager usage
- Git and GitHub basics

## Problem Solving

During deployment I worked through several real-world issues, including:

- Shared hosting limitations
- WordPress migration challenges
- Backup restoration
- FTP connectivity
- Plugin compatibility
- Caching issues

## Key Takeaways

- Always maintain reliable backups before deployment.
- Test changes in a local environment first.
- Free hosting providers often have limitations that affect migrations.
- Troubleshooting is a structured process of isolating, testing, and validating solutions.
- Clear documentation makes future maintenance and collaboration easier.
