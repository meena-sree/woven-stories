# Deployment

## Local Development

- LocalWP
- WordPress
- WooCommerce
- Git

## Deployment Process

The deployment process included:

- WordPress installation using Softaculous
- Backup creation using UpdraftPlus
- FTP configuration using FileZilla
- Shared hosting setup
- SSL configuration
- WordPress migration attempts
- File manager usage
- Database restoration attempts

## Challenges Faced

- Shared hosting upload size limitations
- Backup restoration issues
- FTP troubleshooting
- Hosting-specific restrictions
- Migration plugin limitations

## Outcome

Although deployment to a free hosting provider was limited by hosting restrictions, the project provided practical experience in WordPress deployment, migration, hosting configuration, and troubleshooting.
