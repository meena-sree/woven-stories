# Setup Guide

## Prerequisites

- LocalWP
- WordPress
- PHP 8.x
- MySQL
- Git
- GitHub

## Local Installation

1. Create a new site in LocalWP.
2. Install WordPress.
3. Install and activate:
   - WooCommerce
   - Astra
   - Spectra
   - SureRank
   - Wordfence
   - UpdraftPlus
4. Configure WooCommerce.
5. Create products and categories.
6. Configure SEO.
7. Optimize images and performance.
8. Configure security.
9. Create backups.

## Deployment

The project was tested for deployment on shared hosting using Softaculous, FTP, and WordPress migration tools.
