# Woven Stories

A modern WooCommerce-powered e-commerce website built with WordPress for a handcrafted products business.

This project was developed as part of my WordPress learning journey while preparing for remote product support and Happiness Engineer roles. The focus was not just on building an online store, but also on understanding deployment, SEO, performance optimization, security, backups, and troubleshooting.

---

## Project Highlights

- Built a complete WooCommerce store
- Configured products and product categories
- Responsive design using Astra
- SEO optimization with SureRank
- XML Sitemap and robots.txt configuration
- Performance optimization
- Security hardening using Wordfence
- Automated backups with UpdraftPlus
- Local development using LocalWP
- Deployment experiments using shared hosting
- FTP-based file management
- WordPress migration and troubleshooting
